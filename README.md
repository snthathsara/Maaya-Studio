# Maaya Studio (Pvt) Ltd — Premier Wedding & Fine Art Photography Portfolio

Official web experience for **Maaya Studio (Pvt) Ltd**, Colombo's premier wedding cinematography and portrait studio located along Galle Road, Colombo 06, Sri Lanka.

## ✨ Highlights & Features

- **Google Business Integration**:
  - **4.5 ★ Rating** across **53 Google reviews**.
  - Direct links to Google Directions, Reviews, and 360° Photosphere Street View.
  - Studio contact info: **077 556 2020** (`+94 77 556 2020`) & direct WhatsApp action.
  - Studio Address: No. 24/10, Fedrica Road, Galle Rd, Colombo 6.
  - Operating Hours: Open Daily, 8:00 AM – 9:00 PM.

- **Cinematic Visuals & Experiences**:
  - **Hero Section**: High-bitrate 1080p background video with seamless frame 0 crossfade poster and animated typography.
  - **Story & Heritage**: Emotive narrative honoring Poruwa ceremonies, Hindu and Christian traditions, and coastal romance.
  - **Signature Services**: Wedding Day multi-camera 4K cinema & drone coverage, romantic destination pre-shoots (Galle Fort, Nuwara Eliya, Bentota), and heirloom album production.
  - **Curated Gallery**: Filterable photo gallery by *Signature Weddings*, *Destination Pre-Shoots*, *Traditions & Rituals*, and *Portraits & Regalia* with full EXIF lightbox viewer.
  - **Production Suite**: Sony FX3 Cinema Line, Sony α7R V 61MP, G Master fast primes, and DJI Ronin stabilization.
  - **Interactive Album Configurator**: Live customized price estimation in Sri Lankan Rupees (Rs. / LKR) for handcrafted Italian leather and crystal acrylic flushmount albums.
  - **Light / Dark Mode**: Seamless toggle between warm museum linen and midnight obsidian palettes.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🚀 Development & Preview

# Install dependencies
npm install

npm run dev

# Build for production
